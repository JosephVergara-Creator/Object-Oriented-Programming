# Object-Oriented Programming

A repository dedicated to mastering **Object-Oriented Programming (OOP)** principles. This space documents my academic coursework and personal explorations into design patterns, architectural logic, and the core pillars of the paradigm.

## About

This repository contains a series of exercises and projects developed as part of my Object-Oriented Programming course, using **Java**. Each activity builds on the previous one, progressively applying core OOP concepts such as encapsulation, inheritance, polymorphism, abstraction, and class design through UML diagrams.

## Tech Stack

- **Language:** Java
- **Design tools:** UML diagrams
- **Version control:** Git / GitHub

## Getting Started

### Prerequisites

- [Java JDK](https://www.oracle.com/java/technologies/downloads/) (version 8 or higher recommended)
- An IDE such as [IntelliJ IDEA](https://www.jetbrains.com/idea/), [Eclipse](https://www.eclipse.org/), or [NetBeans](https://netbeans.apache.org/) (optional, but recommended for GUI activities)

### Running the exercises

1. Clone the repository:
   ```bash
   git clone https://github.com/JosephVergara-Creator/Object-Oriented-Programming.git
   ```
2. Open the desired activity folder in your IDE, or compile and run manually:
   ```bash
   cd "Actividad X - Ejercicios"
   javac NameOfFile.java
   java NameOfFile
   ```
